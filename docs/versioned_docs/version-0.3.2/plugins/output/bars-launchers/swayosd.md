# swayosd

Generate colour themes for [SwayOSD](https://github.com/ErikReider/SwayOSD) on-screen display.

## Description

SwayOSD provides on-screen volume/brightness indicators for wlroots-based compositors. The plugin generates a CSS file that styles the OSD popups.

## Output path

```
~/.config/swayosd/style.css
```

## Usage

```bash
tinct generate -i image -p ~/wallpaper.jpg -o swayosd
```

## Flags

| Flag | Default | Description |
|------|---------|-------------|
| `--swayosd.output-dir` | `~/.config/swayosd` | Output directory for theme files |

## Themed elements

The theme affects:

- OSD window background
- Progress bar colours
- Icon colours
- Text colours
- Border styling

## Generated format

```css
/* SwayOSD theme generated by tinct */

window {
    background-color: rgba(30, 30, 46, 0.9);
    border-radius: 16px;
    border: 2px solid #89b4fa;
}

.container {
    margin: 16px;
}

progressbar {
    min-height: 6px;
    border-radius: 3px;
    background-color: #313244;
}

progressbar progress {
    background-color: #89b4fa;
    border-radius: 3px;
}

image {
    color: #cdd6f4;
}
```
